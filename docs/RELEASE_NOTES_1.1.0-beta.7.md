# Blocksphere 1.1.0-beta.7

Linux x86-64 prerelease, 2026-10-11.

- Configure seven Graphics settings together inside Options.
- Remap Controls with original low-resolution game typography and device-aware labels.
- Shared chamfered frames, aligned rows and focus-following brackets replace the permanent filled footer highlight.
- Main menu order: Single, VS, Practice, Training, Options, Close Game.
- Initialize all five Options rows before entry animation, including Graphics.
- Preserve wide framebuffer background captures across the audited transition routes.

No standalone configurator or new Windows binary is included. Physical controller validation, native Windows acceptance and exhaustive late-game transition playthroughs remain pending. Original ROMs, extracted assets, captures and private data are excluded. Project direction, playtesting and original port work: djultra64. Authentic upstream copyright and license notices are preserved.
