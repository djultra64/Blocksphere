# Blocksphere 1.1.0

Linux x86-64, 2026-10-11.

- Configure graphics and controls directly from Options.
- View all seven graphics settings together in one screen.
- Enjoy clearer control menus with original pixel typography, aligned rows and moving selection markers.
- Controller button names follow Xbox, PlayStation and Nintendo Switch layouts.
- Main menu order: Single, VS, Practice, Training, Options, Close Game.
- Options opens with all five entries together.
- Screen transitions preserve the background proportions.

Extract the Linux package and run `./tetrisphere`. Supply your own supported Tetrisphere US NTPE revision 0 ROM when prompted. When updating, copy your existing `data/` directory into the new game folder to keep your settings and progress.
