# Blocksphere 1.2.1

- Install Blocksphere in a folder you choose with the included launcher.
- Add Blocksphere to Steam with optional artwork suggestions from SteamGridDB.
- Use Apply to save Graphics changes and select Unlimited under Frame Rate.
- Play with corrected Linear-filter menu backgrounds, widescreen medal clipping,
  and Rescue magic placement.

Extract the download and run the launcher. Bring your own Tetrisphere US NTPE
revision 0 ROM. Linux x86-64 requires glibc 2.43 or newer, SDL3, D-Bus, and a
Vulkan-capable graphics driver. Windows x86-64 requires the Microsoft Visual C++
Redistributable (x64). To update, install into a new folder and copy your
previous installation's `data/` directory before selecting Play.
